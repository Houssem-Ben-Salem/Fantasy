# Major versions are capped deliberately. CI installs fresh on every run, so an
# unbounded `pulp>=2.7` picked up PuLP 4.0 three hours after its release on
# 25 Sep 2026 — 4.0 stopped bundling CBC — and every daily run failed from then
# on. A new major is a migration to do on purpose, not something to discover
# from a red deadline-day run. Raise a cap only after `make test` passes on it.
pandas>=2.0,<4
numpy>=1.24,<3

pulp>=2.7,<4       # 4.x: CBC moved to the `pulp[cbc]` extra and Python >=3.12
highspy>=1.15,<2   # MILP fallback where PuLP's bundled CBC cannot execute
                   # (macOS ships it as x86_64 only; Apple Silicon without Rosetta)
